# Playwright MCP Testing Project

This project tests the Playwright MCP (Model Context Protocol) functionality by demonstrating various browser automation capabilities.

## Features Tested

1. **Navigation** - Navigate to different URLs
2. **Screenshots** - Capture full page and element screenshots
3. **Form Interactions** - Click buttons, fill forms, select options
4. **JavaScript Execution** - Execute custom JavaScript in the browser
5. **Console Logs** - Retrieve and filter console logs
6. **HTTP Requests** - Test GET/POST/PUT/DELETE operations
7. **PDF Generation** - Save pages as PDF files
8. **Browser Management** - Handle tabs, navigation history

## Test Results

All screenshots and test results are documented in the `screenshots/` directory.
